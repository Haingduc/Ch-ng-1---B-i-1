        <button class="collapsible">I. Khái niệm tính đơn điệu của hàm số <span>▼</span></button>
        <div class="collapsible-content">
          <p>Cho hàm số $y = f(x)$ xác định trên khoảng $(a; b)$:</p>
          <ul style="margin-left: 20px; margin-top: 8px;">
            <li>Hàm số $y = f(x)$ được gọi là <strong>đồng biến</strong> (tăng) trên $(a; b)$ nếu:
              $$\forall x_1, x_2 \in (a; b), x_1 < x_2 \implies f(x_1) < f(x_2)$$
            </li>
            <li>Hàm số $y = f(x)$ được gọi là <strong>nghịch biến</strong> (giảm) trên $(a; b)$ nếu:
              $$\forall x_1, x_2 \in (a; b), x_1 < x_2 \implies f(x_1) > f(x_2)$$
            </li>
          </ul>
        </div>

        <button class="collapsible">II. Điều kiện cần và đủ để hàm số đơn điệu <span>▼</span></button>
        <div class="collapsible-content">
          <p>Cho hàm số $y = f(x)$ có đạo hàm trên khoảng $K$:</p>
          <ul style="margin-left: 20px; margin-top: 8px;">
            <li>Nếu $f'(x) \ge 0, \forall x \in K$ và $f'(x) = 0$ chỉ tại một số hữu hạn điểm thì hàm số <strong>đồng biến</strong> trên $K$.</li>
            <li>Nếu $f'(x) \le 0, \forall x \in K$ và $f'(x) = 0$ chỉ tại một số hữu hạn điểm thì hàm số <strong>nghịch biến</strong> trên $K$.</li>
            <li>Nếu $f'(x) = 0, \forall x \in K$ thì hàm số không đổi (hằng số) trên $K$.</li>
          </ul>
        </div>

        <button class="collapsible">III. Quy trình 4 bước xét tính đơn điệu <span>▼</span></button>
        <div class="collapsible-content">
          <ol style="margin-left: 20px;">
            <li><strong>Bước 1:</strong> Tìm tập xác định $D$ của hàm số.</li>
            <li><strong>Bước 2:</strong> Tính đạo hàm $y' = f'(x)$. Tìm các điểm $x_i \in D$ mà tại đó $f'(x_i) = 0$ hoặc $f'(x)$ không xác định.</li>
            <li><strong>Bước 3:</strong> Sắp xếp các điểm $x_i$ theo thứ tự tăng dần và lập <strong>Bảng biến thiên</strong> (BBT).</li>
            <li><strong>Bước 4:</strong> Kết luận các khoảng đồng biến, nghịch biến từ BBT.</li>
          </ol>
        </div>

        <button class="collapsible">⚠️ Các lỗi sai thường gặp khi làm bài <span>▼</span></button>

          <p>❌ <strong>Lỗi 1 (Kí hiệu kết luận):</strong> Viết khoảng đồng biến/nghịch biến dạng $K_1 \cup K_2$ hoặc $K_1 \setminus \{x_0\}$.<br>
          👉 <em>Chữa đúng:</em> Phải ghi tách rời bằng từ <strong>"và"</strong> hoặc dấu chấm phẩy, ví dụ: <em>"đồng biến trên $(-\infty; 1)$ và $(1; +\infty)$"</em>.</p>
          <p style="margin-top: 8px;">❌ <strong>Lỗi 2 (Dấu '=' với hàm phân thức nhất biến):</strong> Cho hàm $y = \dfrac{ax+b}{cx+d}$, tính $y' = \dfrac{ad-bc}{(cx+d)^2}$. Khi xét hàm số đồng biến lại cho $y' \ge 0$.<br>
          👉 <em>Chữa đúng:</em> Đối với hàm nhất biến, đạo hàm $y'$ <strong>không bao giờ bằng 0</strong> trên các khoảng xác định. Do đó chỉ xét $y' > 0$ hoặc $y' < 0$ (không có dấu '=').</p>
        </div>

    function getF(type, x) {
      if (type === '1') return x * x * x - 3 * x; // x^3 - 3x
      if (type === '2') return -x * x * x + 3 * x; // -x^3 + 3x
      if (type === '3') return Math.pow(x, 4) - 2 * x * x; // x^4 - 2x^2
      return 0;
    }

    function getFPrime(type, x) {
      if (type === '1') return 3 * x * x - 3;
      if (type === '2') return -3 * x * x + 3;
      if (type === '3') return 4 * x * x * x - 4 * x;
      return 0;
    }

    function drawSim() {
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      // Draw grid & axes
      ctx.strokeStyle = getComputedStyle(document.body).getPropertyValue('--border-color') || '#e2e8f0';
      ctx.lineWidth = 1;

      // Grid lines
      for (let x = originX % scale; x < canvas.width; x += scale) {
        ctx.beginPath(); ctx.moveTo(x, 0); ctx.lineTo(x, canvas.height); ctx.stroke();
      }
      for (let y = originY % scale; y < canvas.height; y += scale) {
        ctx.beginPath(); ctx.moveTo(0, y); ctx.lineTo(canvas.width, y); ctx.stroke();
      }

      // Axes
      ctx.strokeStyle = getComputedStyle(document.body).getPropertyValue('--text-color') || '#000';
      ctx.lineWidth = 2;
      // X Axis
      ctx.beginPath(); ctx.moveTo(0, originY); ctx.lineTo(canvas.width, originY); ctx.stroke();
      // Y Axis
      ctx.beginPath(); ctx.moveTo(originX, 0); ctx.lineTo(originX, canvas.height); ctx.stroke();

      // Axis Labels
      ctx.fillStyle = getComputedStyle(document.body).getPropertyValue('--text-color') || '#000';
      ctx.font = '12px sans-serif';
      ctx.fillText('O', originX - 12, originY + 15);
      ctx.fillText('x', canvas.width - 15, originY - 8);
      ctx.fillText('y', originX + 8, 15);

      const type = funcSelect.value;
      const x0 = parseFloat(xSlider.value);
      const y0 = getF(type, x0);
      const k = getFPrime(type, x0);

      // Update Info text
      document.getElementById('xVal').innerText = x0.toFixed(2);
      document.getElementById('pointX').innerText = x0.toFixed(2);
      document.getElementById('pointY').innerText = y0.toFixed(2);
      document.getElementById('slopeVal').innerText = k.toFixed(2);

      const statusEl = document.getElementById('trendStatus');
      if (Math.abs(k) < 0.05) {
        statusEl.innerText = "Điểm cực trị (Tiếp tuyến nằm ngang, k = 0)";
        statusEl.style.color = "var(--warning-color)";
      } else if (k > 0) {
        statusEl.innerText = "Đang đi lên (Đồng biến, f'(x) > 0)";
        statusEl.style.color = "var(--success-color)";
      } else {
        statusEl.innerText = "Đang đi xuống (Nghịch biến, f'(x) < 0)";
        statusEl.style.color = "var(--danger-color)";
      }

      // Draw Function Curve
      ctx.strokeStyle = '#2563eb';
      ctx.lineWidth = 2.5;
      ctx.beginPath();
      let first = true;
      for (let px = 0; px <= canvas.width; px += 2) {
        let x = (px - originX) / scale;
        let y = getF(type, x);
        let py = originY - y * scale;
        if (first) { ctx.moveTo(px, py); first = false; }
        else { ctx.lineTo(px, py); }
      }
      ctx.stroke();

      // Draw Tangent Line
      ctx.strokeStyle = k >= 0 ? '#16a34a' : '#dc2626';
      ctx.lineWidth = 2;
      ctx.setLineDash([5, 5]);
      ctx.beginPath();
      let tanX1 = x0 - 2;
      let tanY1 = y0 + k * (tanX1 - x0);
      let tanX2 = x0 + 2;
      let tanY2 = y0 + k * (tanX2 - x0);
      ctx.moveTo(originX + tanX1 * scale, originY - tanY1 * scale);
      ctx.lineTo(originX + tanX2 * scale, originY - tanY2 * scale);
      ctx.stroke();
      ctx.setLineDash([]);

      // Draw Point P(x0, y0)
      const px0 = originX + x0 * scale;
      const py0 = originY - y0 * scale;
      ctx.fillStyle = '#dc2626';
      ctx.beginPath();
      ctx.arc(px0, py0, 6, 0, 2 * Math.PI);
      ctx.fill();

      renderMath();
    }

    function parseShortAnswer(val) {
      if (!val) return null;
      let cleaned = val.trim().replace(',', '.').replace('−', '-');
      // If fraction a/b
      if (cleaned.includes('/')) {
        let parts = cleaned.split('/');
        if (parts.length === 2) {
          let num = parseFloat(parts[0]);
          let den = parseFloat(parts[1]);
          if (!isNaN(num) && !isNaN(den) && den !== 0) {
            return num / den;
          }
        }
      }
      let num = parseFloat(cleaned);
      return isNaN(num) ? null : num;
    }
